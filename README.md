
# COVID-19 Data Analysis Project

## Project Overview

This project focuses on analysing COVID-19 data using **SQL in Databricks**. The goal was to clean, explore, and analyse COVID-19 data to identify important patterns and statistics across different countries.

The project demonstrates my ability to work with real-world datasets, perform data cleaning, write SQL queries, and extract meaningful insights from data.

## Tools & Technologies

* **Databricks**
* **SQL**
* **Excel**
* **Power BI**

## Dataset

The dataset contains COVID-19 information across multiple countries and includes data related to:

* COVID-19 cases
* New cases
* COVID-19 deaths
* New deaths
* ICU admissions
* Hospital admissions
* Population
* Vaccination information
* COVID-19 testing

The data covers the period from **January 2020 to April 2021**.

## Data Cleaning

Before analysing the data, I performed several cleaning steps in Databricks.

These included:

* Checking the number of rows and columns
* Reviewing column names and data types
* Checking for missing values
* Identifying and removing duplicate records
* Removing columns that were not required for the analysis
* Checking country categories and values
* Verifying the dataset after cleaning

Columns removed from the analysis included:

* Positive Test Rate
* First Dose Pct
* Fully Vaccinated Pct
* Booster Pct
* Cases Per 100k
* Deaths Per 100k
* Hospital Bed Occupancy Pct
* COVID Tests

## Power BI Dashboard

The cleaned and analysed data was used to create a **COVID-19 Dashboard in Power BI**.

The dashboard presents key COVID-19 statistics and country comparisons in an interactive format.

### Dashboard Objectives

* Monitor COVID-19 cases and deaths
* Compare countries
* Identify countries with high and low COVID-19 impacts
* Analyse death rates
* Provide an easy-to-understand overview of the dataset
